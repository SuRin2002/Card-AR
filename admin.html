File nhận diện dùng chung

Tất cả card phải nằm trong cùng một file .mind. Nếu thay file .mind, hãy bảo đảm các giá trị targetIndex bên dưới khớp với thứ tự ảnh trong file mới.
Nếu chọn file mới, Admin tải lên Cloudinary và cập nhật mindUrl chung cho tất cả card đang có.

Thêm Card mới

targetIndex là vị trí ảnh trong file .mind: ảnh đầu tiên = 0, ảnh thứ hai = 1, ảnh thứ ba = 2... Mỗi card phải có targetIndex riêng, không được trùng nhau.
Nhập đúng vị trí ảnh trong file .mind đã biên dịch.
Chọn ảnh gốc để tải lên Cloudinary.
